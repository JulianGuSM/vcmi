**VCMI 冒险地图右键预览增强**

中文 | [English](README.md)

本版本在 VCMI 引擎中增加了冒险地图信息预览。对地图中已经可见的地点或野怪长按右键，即可查看下列信息，无需先派英雄访问。

| 对象 | 新增内容 |
|---|---|
| 城镇 | 在原有城镇面板下方显示本局城镇的魔法图标，按魔法等级从低到高分组排列。已建等级使用彩色图标，未建或禁建等级使用暗灰图标；包含图书馆额外魔法的建设状态。所有图标同时显示，数量较多时自动换行、缩小，不使用滚轮，不显示等级标签或“未建”文字。 |
| 魔法圣殿 | 在原有文字下方居中显示可学习的魔法图标，并标明当前英雄“已学会”或“未学会”。 |
| 女巫小屋 | 在原有文字下方居中显示可学习的辅助技能图标，并标明当前英雄“已学会”或“未学会”。 |
| 学者 | 用图标显示提供的主属性、辅助技能或魔法奖励。技能和魔法显示当前英雄的学习状态；若英雄无法学习原奖励，另行显示按原有规则获得的替代奖励。 |
| 宝屋类地点 | 墓室、狮鹫宝屋、美杜莎宝屋、沉船、废弃船只、龙之国等地点显示实际守军分组，每队单独显示图标和数量，同种兵也不合并；下方用图标显示奖励及数量。已领取的奖励不再作为可获得奖励展示。 |
| 潘多拉魔盒 | 未打开时即可查看奖励图标，包括资源、经验、兵种、宝物、魔法等。有守军时在奖励上方显示分组兵力；无守军时直接显示奖励。 |
| 黑市 | 显示当前在售宝物的图标和名称，跳过已售出的空位；没有库存时显示提示。 |
| 地上的魔法卷轴 | 显示卷轴对应的魔法名称和图标，并标明当前英雄是否已学会该魔法。 |
| 野外怪物 | 顶部按战斗规则显示分组图标及每组精确数量，下方显示精确总数和兵种名称，例如“112 蜥蜴人”。保留启用界面增强时的兵种、等级和威胁说明，并在最下方显示加入意愿。 |

野怪加入意愿根据当前选中英雄，复用引擎实际遭遇时的判定规则，显示“愿意加入”“愿意加入，但需要金币 N”“这些弱小的生物一定会闻风而逃”或“誓死抵抗”，无需透视之眼。付费提示显示野怪的要价；能否支付、部队是否有空位仍由实际遭遇处理。

未选择英雄时，魔法和技能的学习状态显示“（未选择英雄）”。野怪仍显示精确数量；需要英雄才能确定的分组和加入意愿会提示选择英雄。换选英雄后重新打开弹窗，会更新对应信息。存在唯一升级兵种时显示对应的升级分组；模组提供多种随机升级选项时，以问号提示尚未确定的兵种。

此次界面修正还包括：

- 学习状态文字完整居中显示，“（未选择英雄）”的右括号不会单独换行。
- 经验奖励使用完整方形图标，修正金框内下方留白过大的问题，数值居中显示在图标下方。
- 恢复野怪的“数量＋名称”文字行，以各分组数量之和替代模糊数量区间。
- 新增提示提供中文和英文翻译。

预览读取地点当前已有的信息，不会触发访问、发放奖励或改变战斗与外交规则，也不会揭开地图迷雾。城镇魔法列表表示城镇提供的内容，实际学习仍取决于魔法书、智慧术等条件。随机奖励或多选奖励会标明其性质；访问脚本临时生成的奖励不在静态预览范围内。
